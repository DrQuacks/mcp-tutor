### Exercise Creation Workflow
1. Create JSON file in `exercises/` folder with:
   - Exercise metadata (title, description, requirements, hints)
   - Starter code template
   - Solution code
   - Test cases (browserTests for React, tests for Node)
   
   **CRITICAL browserTest Guidelines:**
   
   **Test Isolation (Common Mistake!):**
   - Page reloads before EACH test = complete isolation
   - Tests do NOT share state between them
   - If Test 2 needs "item A" and "item B", it must add BOTH items itself
   - ❌ WRONG: Test 1 adds "A", Test 2 adds "B" and expects both
   - ✅ RIGHT: Test 1 adds "A", Test 2 adds "A" AND "B" then checks both
   
   **Test Coverage (Be Thorough!):**
   - Test ALL interactive features, not just element presence
   - For toggles/state changes, test BOTH directions
   - Example: If clicking toggles strikethrough, test clicking once (on) AND twice (off)
   - Cover: empty states, multiple items, edge cases
   
   **Technical Constraints:**
   - Supported actions: 'click' and 'type' only
   - Supported assertions: exists, expected (exact match), contains (partial match)
   - Do NOT use: count, fill, getStyle, or other unsupported actions
   
2. Call `tutor_react_exercise_prompt` or `tutor_node_exercise_prompt`
3. System automatically:
   - Generates starter file with embedded requirements
   - Updates App.tsx (for React)
   - Student is ready to code
